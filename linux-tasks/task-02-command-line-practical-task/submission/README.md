- **`commands_used.txt`** - the complete, real, numbered (1-64) command
  history for the task, manually reconstructed in `nano` to merge the true

  every phase of the task, including mistakes and their fixes.

  `evidence/screenshots/14-tree-with-permissions.png`
  (`tree -apug project` output).

the `tree -apug` screenshot serves the equivalent purpose.

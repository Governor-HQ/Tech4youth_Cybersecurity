# Linux Tasks

Linux command line practicals from the [Tech4Youth Cybersecurity](../README.md)
course, completed on Kali Linux.

| Task | Focus | Folder |
|---|---|---|
| 01 | User creation, workspace setup, file operations, `chmod`, ownership with `chown` | [`task-01-secure-file-management-user-configuration`](task-01-secure-file-management-user-configuration/) |
| 02 | Directory and file management, `nano`, `cp` vs `mv`, `chmod` reasoning, backups, `tree` | [`task-02-command-line-practical-task`](task-02-command-line-practical-task/) |

Each task folder has its own README covering the requirements, the workflow,
the commands used, the evidence, and the submission files.
